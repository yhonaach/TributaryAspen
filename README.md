# TributaryAspen

Runs secure, multi-user data stores for embedded systems with a simple, web-based interface.

TributaryAspen is built to be simple and practical, focusing on doing one thing well.

**Why TributaryAspen?**

- Runs secure, multi-user data stores
- for embedded systems with a
- simple, web-based interface

## Key Features

- Runs secure, multi-user data stores
- for embedded systems with a
- simple, web-based interface

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/TributaryAspen.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

TributaryAspen is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
